# Auto Office UI instructions

When changing any user-facing interface in this directory, read and follow `DESIGN_SYSTEM.md` first.

- Treat Apple Human Interface Guidelines as the design baseline.
- Preserve semantic color tokens, safe-area handling, 44px touch targets, legible type, adaptive light/dark appearances, and accessibility media queries.
- Use Liquid Glass only for navigation or floating control layers; keep content surfaces visually solid and simple.
- Prefer content hierarchy and familiar platform behavior over decorative effects.
- New navigation, controls, and motion must remain consistent with the existing system and must not communicate state through color alone.
