# 尺寸标注 · Auto Office

从桌面「尺寸标注器 / 尺刻」移植，保留尺寸线、四点矩形、圆形、节点调整、缩放和图片导出。桌面源项目未修改。

在 Auto Office 的「快捷访问 → 尺寸标注」进入；员工快捷权限沿用 `AcademyAuth`。直接打开子页面会跳转主程序登录。新建图片即创建团队共享项目，同事可直接从项目资料库进入。每张图片和每条标注展示制作员工、最近修改员工。不同员工可编辑同一项目。

## 界面

项目资料库使用系统字体、语义色、原图缩略预览及制作人信息。搜索与「全部 / 我创建的」原生单选分段筛选保持等高，资料库依靠实时订阅和自动补拉更新，不提供常驻刷新按钮；请求失败仍可重试。编辑区提供独立画布、分组属性检查器、缩放与适合窗口操作；Auto Office 仅在尺寸标注子程序中扩展到 1440px，退出后恢复原布局。手机端纵向排列画布和工具，保留全部操作。

同时适配 Light / Graphite、增强对比度、减少透明度、减少动态效果以及放大字号。按钮触控区域至少 44×44px。

手机端独立采用紧凑布局：34px 标题与 44px 添加入口位于同一行，省去桌面的引导副标题；搜索框使用 17px 字号避免 iPhone 聚焦放大，分段筛选视觉高度 32px、触控高度至少 44px。项目以缩略图列表呈现，保留制作人、标注数量和更新时间；空状态没有大卡片和重复创建按钮。普通同步状态位于页底，上传进度和异常状态仍优先显示。编辑属性采用分组实体面板，遵循安全区及系统外观设置。

每次打开项目默认处于浏览模式，可点选标注、缩放和平移；点击项目工具栏「编辑」才开放绘制、节点调整、文字、样式、删除及撤销，点击「完成」恢复浏览。完成编辑不改变自动保存机制。手机浏览和编辑模式均使用双指同时缩放、平移画布：两指距离控制缩放，两指中点控制位置，图片上的同一点持续跟随两指中点。图片适合窗口时也可自由双指拖动；达到缩放上限或下限后反向捏合立即生效，「适合窗口」重置缩放和位置。取消触屏单指/长按拖动画布；单指用于点选或编辑模式下绘制、调整节点。第二指落下时取消草稿并回滚未提交节点修改，按显示帧合并双指移动，避免逐指更新抖动。三指及以上暂停手势，恢复双指时重新确定起点；多指操作结束后须全部抬起再开始单指操作，防止误画。画布使用独立 CSS 位移，不依赖浏览器滚动范围；移动端读取原生 Touch Events 的完整双指坐标，鼠标/笔继续使用 Pointer Events，避免同一次触摸重复处理或被指针取消打断。桌面触控板双指滑动平移，捏合（Ctrl+wheel）缩放；鼠标浏览拖动保持可用，手势仅接管画布区域。

手机项目浏览采用占满可用高度的画布：文件名、简短同步状态、导出和编辑合并到同一工具栏。点文件名展开制作人、文件大小及在线人员；制作与修改员工相同时不重复列名。正常同步和手势提示不再占据独立内容行，同步异常及冲突仍显式呈现。底部「标注」展开可滚动的原生风格抽屉；进入编辑或填写尺寸时展开，完成编辑后收起。手机进入编辑时工具面板默认收起；点击「标注」或填写尺寸时打开。面板在画布下方占独立空间，最高为视口的 38%，不会遮挡绘制区域；「收起」入口始终可用。视口变化时保留图片屏幕缩放比例。旋转或可用空间变化时按原屏幕缩放比例保留视口。画布和面板独立滚动，保留双指缩放与拖动、可访问标签、44px 触控范围和安全区。导出等操作结果以短暂提示显示，不挤压画布。

选中标注使用独立叠加画布显示蓝色轮廓、白色衬线、固定屏幕尺寸的控制点及「已选中」文字；矩形和圆形增加淡色填充。高亮随缩放更新并避让尺寸文字，不写入共享数据或 PNG 导出。

新上传图片生成最长边 480px、最大 64 KiB 的预览，随项目写入 `meta.thumbnailPath`；主图已满足预览限制时直接复用，不重复上传。预览路径支持项目目录内带时间戳的文件名（如 `preview-1789396427100.webp`），不限定为 `preview.webp`。旧项目没有预览、预览 404 或解码失败时，按需读取主图并在本机生成小预览；不修改云端图片、数据库或标注。主图也无法读取时暂时显示占位图，下一次目录自动更新时重试。

目录只在卡片接近视口时加载预览，最多两个并发请求，缓存最多 100 张；搜索及筛选复用缓存，退出时释放对象 URL。预览会先解码验证并限制为最长边 480px、最大 64 KiB 后再缓存，避免在卡片中保留大原图。新建项目时预览生成或上传失败仍允许保存已优化的主图。

## 上传优化

打开图片时持续显示当前阶段：本机压缩、上传图片与预览、保存共享项目、准备画布；已有项目显示读取资料、下载图片、解码与准备画布。进度卡在页面中占据独立空间，滚动时保持可见，不遮挡初始标题、项目工具栏或画布操作区。标题、步骤、图片名称与说明分层显示，未知耗时使用不定加载指示器，不展示虚构的完成百分比；目录刷新和实时同步不会覆盖操作反馈。错误同时展示图标和文字，突出「重试打开」，提供「关闭」次要操作；失败聚焦重试，成功聚焦编辑，关闭提示后恢复到当前页面入口。按钮至少 44px，支持大字体、浅色/深色、增强对比度、减少透明度和减少动态效果。工具初始化完成前禁用选图，加载失败可重新加载。

新图片保存成功后直接使用已确认的项目数据和本机压缩结果进入画布，不再依赖重复下载；画布显示后重新适配窗口。打开及保存阶段 45 秒无结果时显示超时和重试，预览上传最多等待 15 秒。重试复用同一项目 ID、已压缩的图片及已完成的上传；保存结果不确定时先读取核验，避免重复创建项目。失败提示保持可见，支持重试打开或关闭提示。

导出标注图也在本机压缩：最长边 2560px、最大 512 KiB，优先 WebP，兼容回退 JPEG/透明 PNG；超限继续缩小，失败不导出大原图。导出采用点击时的画布快照，显示实际文件大小。

`image-processing.js` 在设备本机处理 JPG、PNG、WebP，原文件限制 15 MiB。超过 2400 万像素的图片也自动按比例缩小并压缩，不再按原图像素数拒绝处理；旧项目大图生成预览时同样自动缩小。优先转换为 WebP，主图最长边不超过 2560px、最大 1 MiB；初始质量 0.84，超限时降低质量并按比例缩小，始终从解码后的源图重绘，处理画布不超过目标尺寸。保留透明背景并按 EXIF 方向解码；不放大小图。已有小文件满足尺寸和大小限制、且比重新编码结果更小时保留原格式，避免越压越大。

浏览器不支持 WebP 编码时，有透明像素则使用 PNG，否则使用 JPEG；扩展名和上传 MIME 始终对应实际编码。主图压缩失败会停止上传，不回退上传大原图。界面显示处理进度和最终主图大小。

Storage 只上传优化后的主图和可选预览；数据库只保存路径、实际尺寸、文件大小和标注数据，不保存图片二进制或 Base64。标注画布以优化后的实际尺寸初始化。已有项目不重新压缩，保持现有标注坐标。

## 存储与订阅

- 复用主程序 `ACADEMY_CONFIG` 的 `academy_progress` 表和 `cloud-files` Storage，无需新增表、SQL 迁移或额外账号。
- 项目行主键为 `doc:dimensions:<UUID>`，不会混入学习进度；`payload.meta` 保存名称、图片路径、员工和时间，`payload.annotations` 按 UUID 保存标注及删除墓碑。
- 优化主图保存为 `academy/dimensions/<UUID>/image.<ext>`，预览为 `preview.<ext>`；兼容已有项目的 `original.<ext>` 路径。新图片始终建立新项目，避免替换团队正在标注的底图。
- 项目内使用 `postgres_changes`，按精确主键过滤。相同项目使用相同 Presence 主题显示在线员工。目录使用 Broadcast 通知新项目，30 秒兜底刷新；列表每页 100 条，只查询 metadata，不下载全部标注或图片。
- 拖动结束才保存，输入延迟 450 ms 合并发送。保存用 `PATCH ... user_id=eq.<id>&ts=eq.<base>` 做原子版本校验；版本严格递增，服务端返回空行则重新读取合并。
- 不同标注自动合并。同一条标注的编辑/删除冲突保留本机内容，允许选择团队版本或将本机内容另存为新标注。复制时保留 `copiedFrom`，制作人记为当前员工。
- 操作队列按员工和项目写入本机 localStorage，刷新后重新打开项目会恢复；不会自动放弃未确认写入。网络恢复、重新订阅和前台切换会补拉。连接失败每 5 秒兜底读取；无修改时不写数据库。
- 上传成功但创建项目响应不确定时先读取核验，避免错误清理已被项目引用的图片；无法确认时显示状态，需刷新目录检查。未引用的上传对象可能需要后续清理。

## 权限边界

本次沿用 Auto Office 的自建员工登录和现有数据库权限，没有改动线上 RLS。仓库中现有 `academy_progress` 策略允许 anon 访问，员工登录不是 Supabase Auth JWT；因此快捷权限和制作人字段属于应用层约束，**不构成数据库级身份验证、不可篡改审计或跨团队隔离**。项目链接也不是私密授权凭证。需要服务端隔离时，应统一升级 Auto Office 身份体系，以 Supabase Auth/受信服务签发身份，再用成员关系 RLS 同时约束数据库、Storage 和 Realtime，不能仅给本子程序增加前端检查。

## 标注呈现

标签使用独立 SVG 矢量层、固定 13px Medium 屏幕字号和紧凑圆角背景，避免位图缩放导致文字发虚；导出时按相同字形与布局绘制到图片，缩放时重新排版，自动避让尺寸线及其他标签；细引线连接原始测量位置，长文字自动换行。原有「线上居中」设置现在对应「自动避让」，「线上方」对应「优先上方」，历史标注无需迁移。点击移位后的标签仍可选中标注。导出使用独立参考比例，不受当前画布缩放影响。极端密集且图内空间不足时采用最小遮挡位置，可放大继续查看。

字体与呈现集中在 `label-typography.js`：苹方优先，其余设备使用本地 Noto Sans SC Medium（500）；数字与单位添加细空格，仅影响显示。屏幕 SVG 与导出 Canvas 共用绘制指令和基线度量。字体加载后重新测量；加载失败可回退系统字体，不阻塞编辑。字体说明及许可证见 `fonts/README.md` 与 `fonts/OFL.txt`。

鼠标快捷操作：普通滚轮平移，Shift + 滚轮左右平移，Ctrl + 滚轮缩放；Shift 横移兼容浏览器已经转换为水平滚动的事件。

缩放上限统一为原图的 600%（与缩放栏显示一致），放大按钮、Ctrl + 滚轮和双指缩放共用此上限；窗口尺寸变化后也不会超限。

画布工具栏的眼睛按钮可显示／隐藏全部尺寸线、文字与选中节点；隐藏状态只影响本机查看，缩放后仍保持。导出始终包含标注；新图片、进入编辑或从列表选中标注时恢复显示。按钮支持键盘和 44px 触控热区。

尺寸线可在「文字位置」选择「线内箭头」：两端箭头、居中无底框文字、文字两侧断线。按当前显示比例测量，线段不足以容纳单行文字与两端箭头时自动回退外置标签；缩放后重新判断，导出也按导出比例判断。选项随标注保存，不改动测量端点。矩形和圆形继续使用自动避让。


## 分类目录与持久图片缓存

资料库默认按当前目录显示图片，可新建任意层级子目录，沿路径按钮返回上级；打开图片后在文件详情中选择「移动目录」。新上传图片属于当前目录，未分类的旧图片归根目录。「全部 / 我创建的」及搜索均作用于当前目录中已加载的项目。项目查询在云端按 `meta.folderId` 过滤并分页，进入目录不会读取其他目录的图片。目录记录使用 `doc:dimension-folder:<UUID>`，共享创建与现有员工权限一致，不增加数据库权限。

`image-cache.js` 使用 SHA-256 内容寻址、校验和 Cache Storage 持久缓存。原图与本机生成的小预览在刷新后继续复用，同一图片的并发读取合并；新上传记录 `meta.imageHash`，旧图片首次读取后保存稳定路径到内容哈希的映射。图片路径遵循已有不可替换底图约定，修改标注或名称不触发图片重新下载。缓存最多保留 240 个条目；缓存被浏览器回收、空间不足或不可用时正常回退下载。缓存不存储登录凭据。

2026-11-03 已核对线上 55 张图片，53 张按内容命名，保留 2 张已有中文名称；保留 `originalName` 并分入后厨设备（16）、操作与收纳（14）、餐厅家具（6）、门窗与空间（14）、餐具（5）。只更新项目元数据，保留原图、标注和原制作员工，整理操作记录为 Codex。

`tests/dimensions-folders-browser.js` 使用本地模拟接口验证多级目录、路径导航、目录持久化、当前目录筛选、图片移动、上传内容哈希、并发下载去重和刷新后缓存复用，不写生产数据。

### 整个文件夹的移动与删除

每行右侧「•••」打开文件夹管理，先显示包含全部下级的子目录数及图片数。移动保留整个子树和图片归属，目标列表排除自身及下级；服务端另检查循环、目标存在性和同名目录。

删除默认「保留图片及标注，移到上级目录」，会删除该文件夹及所有下级文件夹，将其中图片统一移至原文件夹的上级。另可明确选择「连同所有图片项目及标注一起删除」。确认前显示范围，支持取消；无法在界面撤销。删除图片项目仅删除数据库记录，Storage 原始上传对象及设备图片缓存不会在事务内物理清除，后续清理应使用独立的无引用对象回收流程。

`sql/dimension_folders.sql` 提供 `dimension_folder_action` RPC（inspect / move / delete_keep / delete_all），使用 SECURITY INVOKER 沿用现有表权限与 RLS；没有新增数据库级员工鉴权。短事务锁定 academy_progress 写入，校验目录及图片版本快照后整体提交，内容变化时拒绝过期确认。短暂表级写锁也会串行化同期学习记录写入，后续资料规模增长可拆分目录表。父目录触发器阻止旧客户端把数据写进已删除目录。网络结果不确定时不自动重放删除，提示重新读取并确认。2026-11-03 已应用后台迁移并以 anon 角色验证只读检查；没有移动或删除线上用户数据。

`tests/dimension-folders-sql.test.mjs` 使用 PGlite 执行实际 SQL，检查子树移动、循环拒绝、同名拒绝、过期删除拒绝、保留图片及标注、递归删除和旧客户端父目录检查；浏览器测试补充操作入口、排除目标、范围提示、取消、两种删除方式。

### 目录加载反馈与首页优化

资料库与目录切换立即显示加载文字和旋转指示；首次无内容时使用占位行，不提前显示空目录。缩略图在本地缓存读取、网络下载及解码期间持续显示「加载中」，完成后短暂淡入；失败显示不可用状态。减少动态效果时停止动画，保留文字和静态指示。目录请求超时或失败保留已有内容并显示重试入口。

基础脚本并行加载；文件夹列表和当前目录图片 metadata 并行请求，独立呈现，首页文件夹不再等待图片列表。会话内缓存最近 20 个目录的 metadata，返回时先显示本机记录再与云端同步；缓存不是最终云端状态。新目录导航使旧响应失效，旧请求不会阻塞当前目录或覆盖其结果。后台同步数据未变化时保留图片卡片及文件夹 DOM，避免闪烁、重复解码和丢失键盘焦点。图片仍按视口懒加载、最多两个预览并发，网络预览设置 15 秒超时，继续复用 SHA-256 持久缓存。

`tests/dimensions-loading-browser.js` 使用可控慢响应验证并行首屏、即时反馈、无错误空状态、慢缓存与慢网络、快速切换的乱序保护、DOM 复用、失败保留内容及重试；首次 4 个预览网络读取，返回目录和刷新后均无新增图片下载。此结果来自本地模拟接口，不代表线上网速测量。

后台同步（定时检查、恢复联网、切回前台、Realtime 订阅与通知）不再显示目录加载动画；已有请求进行时合并重复后台触发，不追加连续刷新。首次打开、切换目录、加载更多及手动重试继续显示加载反馈。浏览器回归模拟连续 24 个联网/可见性事件，确认只发起一轮读取、不显示加载条且保留未变化的卡片。

### 绘制隔离与画布就地操作（2026-11-04）

进入编辑后默认「新建标注」：历史标注保持可见，但其线身、标签和端点完全不参与命中。工具栏选择尺寸线、矩形、圆形也进入新建模式。「选择 / 调整」或列表选择进入选择模式，只有选中且未锁定标注的端点可拖动，拖动线身不会移动标注。浏览模式的画布只平移，不再点击选线；列表仍可用于浏览定位。

新线完成后显示画布就地操作条：填写尺寸、重画、删除、复制、锁定、继续标注。填写尺寸打开已有属性面板；其余动作无需翻找列表。右键历史线（选择模式）定位同一操作条；触屏点选或按住线即可显示操作条，控件触摸不会被画布手势拦截。重画保留原 ID、文字与样式，成功绘制才替换几何；Esc 取消保留原线。锁定状态随标注同步，阻止端点调整和删除，可就地解锁。

## AI 批量编辑

展开项目标题的资料菜单 → **AI 批量编辑**。导出 JSON（原图尺寸、标注 ID、版本和示例），粘贴编辑指令 → 预览修改 → 应用并保存。该入口沿用当前网页登录，不需要 MCP 账号，也不会替换登录会话。预览显示原图方向下完整标注结果；仅用于检查落点与文字，不从照片自动推断真实尺寸。

```json
{
  "projectId": "项目 UUID",
  "expectedVersion": 读取或导出时的整数版本,
  "requestId": "每批唯一 ID，重试必须复用",
  "operations": [
    {"op":"update","id":"已有标注ID","changes":{"label":"宽 140 mm","start":{"x":100,"y":200},"end":{"x":500,"y":200}}},
    {"op":"create","id":"新标注ID","changes":{"type":"line","start":{"x":100,"y":200},"end":{"x":100,"y":600},"label":"高 140 mm"}},
    {"op":"delete","id":"要删除的标注ID"}
  ]
}
```

- 原图左上角为 (0,0)，x 向右、y 向下；坐标不随网页缩放、滚动、旋转改变。
- 一批 1–100 项，每个 ID 只能操作一次。changes 只支持 type、start、end、points、label、labels、style、labelPosition、locked；作者、时间、版本由系统生成。
- 类型 line/rect/circle；circle 的 start 为圆心、end 为圆周上的点。rect 的 points 为四个有序顶点，修改 start/end 且未指定 points 时自动重建顶点。
- 样式 light/dark/outline；文字位置 center/above/inline；矩形 labels 包含 top/right/bottom/left。
- 越界、重复 ID、锁定项、非法字段会使整批拒绝。锁定项需先提交仅含 `locked:false` 的解锁操作。
- 同一项目一行 CAS 保存，不通过逐条 Session.edit 排队，因此不会出现半批保存。任何文档版本冲突都需要重新读取并核对。
- 最新批次的 requestId 和内容签名随项目保存。回包丢失时复用原请求核实，避免重复创建；更早批次的重试由旧版本检查拒绝。
- 撤销上一批先预览，后一次保存。若该批目标标注后来被改动则拒绝撤销；其他未涉及标注保留。只保留最近一次批次收据，撤销不支持连续撤回多个批次。
- 网页对话框关闭后保留本页未提交指令；刷新页面前请自行保留 JSON。保存期间阻止关闭对话框，离开页面有提示。
- `batch.js` 是网页与本机 MCP 共用的纯校验/规划模块；`batch-ui.js` 提供网页入口。未开放跨域 postMessage、任意代码执行或公开写入服务。

隔离浏览器回归：`node scripts/prepare-dimensions-batch-test.mjs` 后用本机静态服务器打开 `/output/dimensions-batch.html`；支持 `?theme=dark&large=1`。使用真实编辑器和协作模块，仅 REST 传输为假数据，无线上写入。
