# 登录地区提示

登录记录在管理员浏览器中查询本站的离线 IP 地区数据。不会将登录 IP、账号或设备识别码发送给第三方 IP 查询服务，不请求 GPS 定位，不修改历史登录记录，也不增加 Supabase 数据。

数据源：[`lionsoul2014/ip2region`](https://github.com/lionsoul2014/ip2region)，固定提交 `c1a1fc7d5941760db3f8431dc05c48cf7f0e30a1`（2026-09-01）。上游 XDB 的数据生成时间、SHA-256 和每个派生文件的校验值保存在 `20260901/manifest.json`。许可证随数据分发。

本站对上游数据进行了格式转换、分区、合并相邻同地区范围和 gzip 压缩；保留国家、省份、城市、运营商和 ISO 地区代码。每个文件最多 8192 个地址范围，当前最大压缩文件约 140 KB，按实际记录需要加载。普通登录页不下载地区库。浏览器只在内存中缓存地区范围，不额外缓存登录日志；地区资源可使用 HTTP 缓存。

构建：下载固定提交的 `data/ip2region_v4.xdb`、`data/ip2region_v6.xdb` 与 `LICENSE.md` 到一个本地目录，运行 `python3 scripts/build-login-geo.py <目录>`。更新数据时同时修改脚本版本、客户端版本目录及公开文件清单，保留旧版本资源以兼容仍打开的页面。不在 CI 中临时下载可变上游数据。

地区仅代表该 IP 在离线数据中的归属，不是实时 GPS 或历史所在地证据，代理、VPN、蜂窝出口和过期地址归属都可能造成偏差。设备名称来自当时已记录的 User-Agent；iPhone 一般不能识别具体型号，Mac 与开启桌面模式的 iPad 也可能无法区分。设备识别码表示浏览器安装，不是硬件序列号。无法识别时明确展示未知，不推断具体设备或入侵结论。
