✅ WEBAPP 1:1 显示功能已实现

实现的功能:

  • 完全样式隔离: 使用 .webapp-isolate 包装器,通过 all: initial 重置所有继承样式
  • 1:1 显示: WEBAPP 内部内容不受外部样式影响,浏览器怎么显示就怎么显示
  • CSS 作用域: 所有 CSS 选择器自动添加 .webapp-isolate[data-webapp-scope="id"] 前缀
  • ID 隔离: 自动重写 HTML 中的 ID,避免冲突
  • JavaScript 隔离: 在独立作用域中执行,提供 $ 和 $$ 查询函数

技术细节:

  • 移除了 .webapp-container.webapp-active 的内边距,让内容完全控制自己的空间
  • 创建 .webapp-isolate 包装器,使用 all: initial 重置所有样式
  • 为常用 HTML 元素恢复默认样式 (使用 all: revert)
  • CSS 选择器自动添加作用域前缀,确保样式只应用到对应的 WEBAPP 实例

使用方法:

在今岭笔记中,使用 [WEBAPP]...[/WEBAPP] 标签包裹你的小程序代码:

[WEBAPP]
<style>
    body {
        background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
        padding: 20px;
        color: white;
    }
    .card {
        background: rgba(255,255,255,0.1);
        padding: 20px;
        border-radius: 10px;
    }
</style>

<div class="card">
    <h1>Hello WEBAPP!</h1>
    <p>这个内容会 1:1 显示,不受外部样式影响</p>
</div>

<script>
    console.log('WEBAPP 已加载');
</script>
[/WEBAPP]
